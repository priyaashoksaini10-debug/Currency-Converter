# Currency Converter 💱

## About the Project

Currency Converter is a responsive web application that allows users to convert an amount from one currency to another using real-time exchange rates.

The project provides a simple and user-friendly interface with a modern **Glassmorphism design effect**, making the application visually attractive while keeping it easy to use.

## Features

- Convert currencies easily by entering an amount
- Supports multiple international currencies
- Fetches exchange rates using a currency exchange API
- Currency selection through dropdown menus
- Displays country flags for selected currencies
- Default conversion from USD to INR
- Real-time conversion results
- Responsive and user-friendly interface
- Modern Glassmorphism UI design
- Clean layout with attractive styling

## Technologies Used

- **HTML** – Used to create the structure of the application.
- **CSS** – Used for styling, responsive layout, and Glassmorphism effects.
- **JavaScript** – Used for currency conversion logic, API integration, DOM manipulation, and dynamic updates.
- **Currency API** – Used to fetch exchange rate data.
- **Flags API** – Used to display currency-related country flags.

## API Used

### Currency API
The project uses the Fawaz Ahmed Currency API to fetch exchange rate information.

### Flags API
Country flags are dynamically displayed using the Flags API.

## How It Works

1. Enter the amount you want to convert.
2. Select the currency you want to convert from.
3. Select the currency you want to convert to.
4. Click the conversion button.
5. The application fetches the latest available exchange rate.
6. The converted amount is displayed on the screen.

## Glassmorphism Design

A **Glassmorphism effect** has been used to give the application a modern and elegant appearance.

The design includes:
- Transparent or semi-transparent elements
- Background blur effects
- Soft borders
- Rounded corners
- Layered visual appearance

This helped me practice creating modern UI designs using CSS.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the project using Live Server or open the HTML file directly in a browser.
5. Select currencies and enter an amount to start converting.
